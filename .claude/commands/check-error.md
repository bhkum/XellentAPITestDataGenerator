# /check-error

Analyze an error log against the API payload, preprocessing script, and API handling class to identify root cause and suggest a fix.

## Usage
```
/check-error <details_file>
```

## Input file format
Read `<repo_root>\TestData\errors\<details_file>` which contains:
- `jsonBody` — the API payload used
- `setupClassName` — the preprocessing script class generated by `/generate`
- `apiClassName` — the API handling class name(s)
- `errorLog` — the raw error log output

## Analysis steps

1. Parse the error log — extract all unique error messages and correlate with payload field values
2. Investigate in this order:

### Step 1 — JSON body
- Check if any field values in the payload are missing, invalid, or referencing data that doesn't exist
- Cross-reference with `registry.json` to see if all `SCRIPT` dependencies were created

### Step 2 — Preprocessing script (`setupClassName`)
- Locate `<setupClassName>.xml` in `J:\AosService\PackagesLocalDirectory\APITestDataGen\APITestDataGen\AxClass\`
- Check if all required prerequisite records were created correctly
- Check for missing dependencies not covered by the setup script

### Step 3 — API handling class (`apiClassName`) — check only if Steps 1 and 2 are clear
- Locate `<apiClassName>.xml` in `J:\AosService\PackagesLocalDirectory\XellentBilling\XellentBilling\AxClass\`
- Trace the validation logic that could produce the error message
- Flag if the issue is in the API class itself — this is rare and cannot be fixed by a script

## Output format

```
ROOT CAUSE
----------
[Step where issue was found: JSON / Setup Script / API Class]
[Clear explanation of what is wrong]

AFFECTED FIELDS
---------------
Field     | Value      | Issue
--------- | ---------- | -----
TST_Produc| ProductNum | Product does not exist in company OAB

SUGGESTED FIX
-------------
[If fixable by script]    → Update setup script to create missing record — run /generate to regenerate
[If fixable by JSON body] → Change field <X> value to <Y>
[If API class issue]      → Manual investigation required — cannot be resolved by script

NEXT STEP
---------
/generate   → if setup script needs update
/analyze    → if JSON body needs to be re-examined
Manual      → if API class issue
```

## Rules
- Investigate one step at a time — do not jump to API class unless Steps 1 and 2 are clear
- Do NOT suggest changes to the API handling class code
- If the fix requires a new prerequisite record, update `registry.json` and instruct to re-run `/generate`
- If cause cannot be determined, flag explicitly — do not guess
